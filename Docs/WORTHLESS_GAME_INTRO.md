# Worthless

**每段交易只能成交一次。你现在就换，还是等大屏再说一句？**

《Worthless》是一款围绕物品交易展开的社交推理派对游戏。每个人开局都拿到一件物品。你能看见别人手里是旧怀表、纸灯还是琥珀坠，但每件物品的当前价值只有持有者能直接查看。有人说自己的怀表很值钱，马上就愿意跟你换。你敢答应吗？

## 一轮怎么玩

1. **找人谈价。** 用文字在公共频道开价、走近对手试探，或进能反锁的私人房间谈条件。双方确认才会交换物品，每人每段最多成交一次，每轮最多三次。
2. **看大屏，再做决定。** 大屏会逐条播报估值线索，其中可能混有谎言。最后一段交易开始前，系统会公布一共有几条假情报，具体哪几条要靠你判断。
3. **争取你的秘密名次。** 得到高价组或低价组目标后，在各组随机指定的第一或第二名上争胜。每轮秘密给另一名玩家 +5 或 -5。非末轮先更新市场，再合并价值修正。末轮直接结算秘密操作。

## 游戏模式

- **单人游戏**可配置 4～9 名 NPC 一同参赛，试试不同的交涉话术。
- **局域网联机**支持与同一局域网内的朋友开房。每局可选 5～10 个席位，空位由 NPC 补齐。
