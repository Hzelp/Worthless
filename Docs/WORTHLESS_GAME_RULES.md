# Worthless 游戏规则与裁定

适用版本 v0.4。玩法概览见 [Worthless 游戏介绍](WORTHLESS_GAME_INTRO.md)。

## 参赛与轮次

【已确认】房主在联机房间或单人准备页设置 5～10 个总席位及总轮数。默认 3 轮，总轮数独立于人数。目标席位不能少于已加入真人，空缺由 NPC 补齐。单人模式固定 1 名真人，10 席和 3 名真人时补 7 名 NPC。所有参赛者参加完整对局。

【实现默认】总轮数可设 1～10。未选人数时采用能容纳真人的最少席位，新增成员超过选定席位时自动上调。5–6／7–8／9–10 人分别开放 1／2／3 间私人房间。

每轮依次进行首段交易、情报广播、第二段交易、谎言数量揭晓、第三段交易和 30 秒秘密价值操作。非末轮随后播放市场特写。交易默认上限为 120／120／60 秒，房主可调。广播每 3 秒增加一条，揭晓 5 秒。任一交易阶段具备交易资格的参赛者不足两名时提前结束该段。

## 交易

【已确认】两个参赛者可同时和不同对象挂起多条请求。只有双方确认同一笔交易后才可交换，对价只有当前持有物。每次被判定为失败的交易记 1 次。累计 2 次失败时，参赛者失去**当前交易阶段**的交易资格，随后交易阶段可重新尝试。任何一次成功使双方失去**当前交易阶段**的交易资格。进入下一交易阶段时，成交资格和失败次数均重置。每轮三段，每人每段最多成交一次。资格耗尽在脚下名牌卡片显示「交易用尽」；对本轮无法换回的对象显示「不可换回」，Tab 关闭时保留状态卡。口头承诺由玩家自行判断。从轮次开始到本轮交易结束，同一物品实例不得被交易回本轮曾交换出该物品的参赛者。下一轮按新一轮资格校验。

### 正常流程

【建议】一条请求绑定局、轮次、阶段、两名参赛者及两件物品实例。发起方点击「发送并确认」即同意所示交换，对方选择确认。双方同意后，权威端按接收顺序处理提交，步骤如下。

1. 确认请求仍待处理、内容版本一致，双方可操作、均参赛、当段未成功且失败均少于两次。复核当前持有物与请求绑定的实例，并确认交换后两件物品均未回到本轮曾交出它的人手中。
2. 在同一提交中交换所有权、登记双方本段成功、记录两份持有历史并终结受影响的挂起请求。资格计数、当前物品和取消结果须来自同一权威版本。
3. 公开更新物品身份与资格标记，仅向新持有者发送各自新物品的当前价值。回执携带请求 ID 和权威版本，客户端据此去重。
4. 权威端重算可交易人数，按资格或截止时间推进阶段。重发相同确认时返回已知结果。

### 失败、边界与并发

| 场景 | 建议结果 | 待确认依据 |
| --- | --- | --- |
| 对方明确拒绝已送达的有效请求 | 发起者在当前交易阶段累计一次失败。同一请求只计一次，向不同玩家发出的请求合并计数。第二次拒绝显示「交易用尽（2/2）」，关闭当前交易入口并终结其本段挂起请求 | 已确认 |
| 发起者撤回、请求到期、换阶段 | 请求终结，提示具体原因。建议不计失败 | Q01、Q02 |
| 任一方已成功、当前物品变动或失去资格 | 新提交失效，终结关联挂起请求。建议不计失败 | Q01、Q02 |
| A↔B 与 A↔C 同时满足确认 | 首个权威成功提交后，后续交易重新检查 A 的资格与物品，拒绝失效交易 | Q04 |
| 截止点前截图还显示可确认，但请求到达时已截止 | 权威端按截止时刻关闭，双方收到「阶段已结束」 | Q04 |
| 已完成的确认被重复发送、网络包乱序 | 返回同一结果或丢弃过期版本，不重复计次或换物 | Q04 |
| 断线时请求挂起、确认已提交但回执未到 | 终结尚未提交的请求，断线取消不计失败。已提交结果随重连快照恢复 | Q08（已定） |

**验收**：A 在第一次交易两次失败后不能再发起或确认，进入第二次交易时可交易。若 A 在第一次交易已成功，本段不能再次成交，第二、第三次交易可与其他符合条件的对象成交。A 与 B 在第一次交易交换后，第二、第三次交易都不能换回；两人进入下一轮后重新具备资格，可确认换回同一对物品实例。

## 情报与市场

【已确认】广播按 3 秒间隔在大屏逐条累积。房主为每席生成固定涂黑正文，回看及重连保留该席版本。揭晓只公开谎言总数。物品精确价值与整局本人价值历史向当前有权查看的本人定向同步。

【表现修正】整条涂黑时，广播与回看只显示固定长度的连续黑条，不显示“本条情报已全部涂黑”等说明，不传输被遮住的原文。黑条长度不随正文、类别、姓名或真假变化。

【已确认】区间端点限制在真实价值上下各 50% 的范围内。例如价值 80 时，所有端点取自 40～120 内的十位数。真区间包含真实价，假区间取在真实价的一侧。负价值按绝对值生成后镜像，例如 -80 的端点范围是 -120～-40。真假按广播开始时的真实价值是否位于完整区间内判定，之后再涂黑。

【实现默认】端点取 10 的整数倍，正常向区间内部取整。只有某一侧找不到可覆盖原价的合法十位端点时，才将该侧向外取到最近的十位数。例如 7 使用 0～10，-7 使用 -10～0，11 使用 10～20。端点候选只剩一个值时可重合，0 的真区间为 0～0。所有候选重新求值后按谎言配额选择。

## 整局日志与成交播报

【已确认】日志跨轮保留到本局结束，回看全部记录。成功交易以小字弹幕在场景大屏下缘飘过，并注明轮次和交易次数。

【实现口径】交易记录标明轮次及「第 1／2／3 次交易阶段」，保留 P 席位号、玩家名字与交换物品。物品实例编号、内部成交序号不在界面或弹幕显示。公共记录冻结成交时双方名字和交换的物品身份，不含真实价格、秘密分组或秘密操作。仅权威成功提交追加一次；拒绝、撤回、过期和重复确认不追加。重连同步全部公共历史，但不将旧记录重新播成实时弹幕。

本人价值日志逐条保留初始物品、成功交换获得物品时的真实价格、市场与秘密修正完成后的合计价格，以及并列加赛后的合计价格。非末轮的合计价格记入下一轮，作为开场价值。末轮和加赛的价格仍归本局最后一轮。取值来自权威计算结果，不由界面推算。曾持有记录的数字固定为当时的真实价格；非当前物品在数字后显示 ↑／↓，表示从该快照起、公开市场对这件物品类别的累计涨跌方向。箭头通过公开倍率逐次计算（包括负值、取整和安全价域），不包含此后未知的秘密修正，也不读取他人私有价；不变时不加箭头。轮末快照已经包含当轮市场，计算箭头时不得重复应用它。仅开始新局时清空。价值日志只在本人价格下方滚动显示，不另开 HUD。交易记录只有靠近场景大屏才能通过 F 或近处回看按钮打开，显示在大屏内部；与本轮情报共用页签，离开范围或阶段变化时关闭。弹幕字号和速度在 Gameplay 的 BroadcastStage Inspector 可调。

【已确认】第三段交易后，所有参赛者在大屏的个人面板选另一名参赛者及 +5 或 -5，每席每阶段仅一次。全员有效提交后立即结束。NPC 提交合法选择，超时未交的人包括掉线者由房主补齐目标和方向。房主校验局、席位、轮次、阶段和截止时间。每席确认回执仅本人可见。

房主锁定选择。非末轮先公布并计算市场，再将所有操作按目标席位求和，应用到结算时该席正持有的物品。末轮和加赛只应用秘密修正。价值随实例传到后续交易和下一轮，可以为负。

## 秘密目标、胜负与加赛

【已确认】开局随机分配高价或低价目标，真人、NPC 一起分配。偶数各半，奇数相差一人。高价组按组内价值降序，低价组按组内价值升序。**两组各自独立随机抽第一或第二**，组合可为一/一、一/二、二/一、二/二。分组和两组目标名次固定到本局结束。界面只向本人显示所属组及该组的目标名次。

开局先在大屏播报本人目标，再进入第一次交易。各端只用自己的目标绘制组别、排序方向与获胜名次。播报每局一次，默认 6 秒，可在 Unity 的 `RoundConfig` 中调整。之后左上角可随时查看个人目标。

完成最后一轮秘密修正后，在各组排序列表中取目标位置对应的价值。达到该价值的参赛者是该组候选胜者，通常各一人。【并列执行口径】同价者共享目标价位，即使该并列跨过第一与第二位置。例如高价组降序 [90, 90, 70] 抽第二时，两名 90 都是候选。

【已确认】任一组候选并列时进入一次秘密操作加赛。全员参与，可选任意其他参赛者，两组按加赛后价值共同重算。沿用 30 秒、全员提前结束、超时随机补齐和 ±5。加赛开始时仅宣布并列加赛，不公布组别、候选人、价格或操作。加赛后仍并列时共同获胜，只公布胜者及其组和目标名次依据。

## 断线与重连

【已确认】房主会话仍在运行时，离线席位保留原物品、秘密目标和已经锁定的选择。离线期间停用移动、通信及交易，未提交交易请求终结，时钟继续。离线席照常参加市场、秘密操作结算和胜负，未提交的选择在截止时随机补齐。

同局可凭席位凭证重连并原子替换连接。恢复当前阶段、原席位、私有目标、有效提交状态、物品和可见历史。旧连接与过期请求失效。房主关闭会话或进程退出时本局中止，房主迁移仍待后续版本。

【已确认】在线参赛者按原权限使用公共、附近及私人房间文字频道。私人房间的反锁和成员权限继续由房主判定。语音仍未接入。
